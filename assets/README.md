# 本节素材

- `chessboard_104435_preview.mp4` 是 640×360 的棋盘格视频，用于角点示范和任务一。
- `task1_camera.npz` 是配套的相机内参、畸变系数、图像尺寸和标注格长。
- `task2_vehicle_materials.zip` 包含任务二的两个黑屏片段、对照原片、目标示意和逐帧数据。
- 白车示范使用 `vehicle_demo_blackout.mp4` 和 `vehicle_center_observations_blackout.csv`。`vehicle_center_observations.csv` 是保留缺测区间原观测的对照表。
