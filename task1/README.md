# 任务一 棋盘格视频中的立方体投影与测距

制作原片第 168–431 帧的离线回放，即从 7.0 秒起到 18.0 秒前，帧号从 0 开始。回放在棋盘上叠加随其运动的立方体，并显示相机到棋盘图案中心的直线距离。

## 输入

- `assets/chessboard_104435_preview.mp4` 为 640×360、24 帧/s 的实拍视频。
- `assets/task1_camera.npz` 提供 `K`、`dist`、`image_size` 和 `square_size_m`。正式回放用板面标注格长 20 mm。
- `lab.inputs.board_frames(start, stop)` 返回原片帧号、时间和 BGR 图像，`stop` 为排他上界。`lab.inputs.load_calibration()` 读取配套标定。

从仓库根目录运行 `python3 -m lab.check_inputs --task 1` 检查素材。

## 回放与尺度对照

立方体边长为两格。底面固定于第 2、4 行与第 4、6 列的四个实物内角点。行列从 1 开始，以棋盘印刷文字正向为准，从上到下数行，从左到右数列。顶面位于棋盘可见的一侧。位姿无效时隐藏线框并标记该帧。

用 17.5 秒验收帧做一次单变量对照。固定像素角点、内参和畸变系数，只把求解用的格长由 20 mm 临时改为 40 mm，重新求位姿。将这次结果追加到原结果表。

## 提交与验收

提交工作分支或 PR 链接、正式回放视频、7.5 秒和 17.5 秒的截图，以及含两帧正式结果和一行尺度对照的结果表。可使用[测量记录模板](measurements.csv)。表中记录光轴深度、直线距离、两者差值和重投影均方根误差，注明单位。

说明回放要显示哪个距离、两个验收帧的差值为什么不同，以及格长改变后各项结果怎样变化。根据对照解释像素回投能检验什么，若要核验实际距离，还需要哪项独立参考。

验收时会在同一原片的另一小段复跑。提交的程序应能通过参数或配置切换起止时间。
