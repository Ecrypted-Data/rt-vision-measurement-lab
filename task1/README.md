# 任务一　棋盘格视频中的立方体投影与测距

在第一段棋盘格视频的 7–18 秒逐帧解算位姿，叠加立方体，同时显示相机到棋盘图案中心的直线距离。

## 已提供的输入

- `assets/chessboard_104435_preview.mp4` 是飞书里的第一段棋盘格视频。任务覆盖原片第 168–431 帧，帧号从 0 开始。
- `assets/task1_camera.npz` 与这段 640×360 视频配套。使用板面标注格长 20.0 mm。
- `lab.inputs.board_frames()` 依次给出原片帧号、时间和 BGR 图像。`lab.inputs.load_calibration()` 读取内参、畸变和格长。

## 结果要求

以内角点的行列从 1 开始编号，以棋盘印刷文字正向为准。立方体的底面固定在第 2、4 行与第 4、6 列的四个交点，边长为两格，顶面朝棋盘可见侧。无法获得有效位姿时隐藏线框，并标记该帧位姿无效。

提交动态叠加视频，以及 7.5 秒和 17.5 秒两帧的截图与结果表。记录光轴深度、直线距离、两者的差值和像素重投影误差。简述回放要显示哪个距离，并解释两个验收帧的差值为什么不同。

可以在仓库根目录运行 `python3 -m lab.check_inputs --task 1` 核对素材。
