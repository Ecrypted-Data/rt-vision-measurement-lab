# 任务二 黑屏前后的车辆轨迹估计

分别追踪右侧深色皮卡和画面中部的红车。每个片段锁定一辆车，在黑屏结束后接回同一辆。每段先得到一条目标观测序列，三种方法都使用这条序列。

## 输入

`assets/task2_vehicle_materials.zip` 包含黑屏版视频、逐帧对齐的清晰视频、首帧目标图、帧表和候选框。运行 `python3 -m lab.check_inputs --task 2` 检查并解包到 `work/vehicle_inputs/`。

`lab.inputs.vehicle_case_files("a")` 或 `vehicle_case_files("b")` 也可以解包指定片段。用 `lab.inputs.vehicle_frames(case, folder)` 读取片段内帧号、原片帧号、秒级时间戳、黑屏标记和候选框。黑屏帧保留在序列里。

| 片段 | 目标 | 原片帧号 | 片段内黑屏帧 | 黑屏参考帧 | 恢复首帧 |
| --- | --- | --- | --- | --- | --- |
| A（`a_`） | 右侧深色皮卡 | 270–305 | 12–19 | 14、18 | 20 |
| B（`b_`） | 画面中部红车 | 791–827 | 10–17 | 12、16 | 18 |

所有帧号从 0 开始。估计时只使用黑屏版及其候选框，只读取当前及以前的帧。清晰视频用于事后人工标记参考中心。

## 参数对照与复验

用同一观测序列和时间轴比较直接输出、指数平滑和线性卡尔曼估计。图表应能辨认纯预测帧。

在皮卡片段上运行两组设置。固定观测序列、时间轴、运动模型、过程噪声 Q、初始状态与初始协方差 P₀。第二组只将测量噪声标准差增至第一组的两倍，即测量噪声协方差 R 变为四倍。用[恢复帧参数对照模板](recovery-comparison.csv)记录两组在第 20 帧的预测位置、观测位置和修正后位置。说明选择哪组及其依据，再用原设置复验红车。记录 P₀ 的初始值，运行中的 P 随预测和修正更新。

## 提交与验收

- 提交工作分支链接、两个片段的轨迹对照图和逐帧结果表。逐帧表含帧号、时间、输入观测、三种输出，以及卡尔曼在该帧是纯预测还是用观测修正。
- 两段各交一张恢复首帧截图，标出实际接回的候选框，简述如何确认车辆身份。先核对车辆身份，再比较位置误差。
- 提交六个参考帧的人工中心与误差。误差为输出中心到人工参考中心的像素距离。每个片段分别报告两处黑屏参考帧和首个恢复帧，并注明各方法的实际输出帧数。直接输出在黑屏段记为缺测，误差留空。可使用[参考帧记录模板](reference-errors.csv)，在现有结果表或 README 补上分段输出帧数和判断。
- 提交两组参数对照、指数平滑权重、Q、R、P₀ 的设置与选择理由。红车复验使用从皮卡片段选出的设置。

验收时会用红车片段的延长缺测版本复跑。程序按输入时间戳、缺测标记及候选框推进预测、修正和目标关联。
