# 任务二　黑屏前后的车辆轨迹估计

分别追踪右侧深色皮卡和中间红车。每段锁定一辆车，黑屏结束后接回同一目标。用皮卡片段选定设置，在红车片段沿用。

## 已提供的输入

`assets/task2_vehicle_materials.zip` 里包含黑屏版、清晰版、首帧目标图、逐帧时间表和车辆候选框。

`lab.inputs.vehicle_case_files("a")` 会解包指定片段到 `work/vehicle_inputs/`。把它返回的目录和片段编号交给 `lab.inputs.vehicle_frames()`，可以按时间读取逐帧候选框。黑屏帧也在序列里。

| 片段 | 目标 | 片段内黑屏帧 | 人工核对中心的片段内帧号 |
| --- | --- | --- | --- |
| A | 深色皮卡 | 12–19 | 14、18、20 |
| B | 红车 | 10–17 | 12、16、18 |

帧号从 0 开始。追踪使用黑屏版及其检测结果。最终评估时，在清晰版对齐的帧中标记车辆中心作为人工参考。

## 结果要求

从候选框中得到指定车辆的观测序列。沿同一时间轴比较直接输出、指数平滑和线性卡尔曼估计。结果图表应能辨认纯预测帧，并显示黑屏恢复后接到的是哪辆车。

提交两个片段的轨迹对照图和逐帧结果表、六个参考帧的位置对照，以及说明所选参数和复验结果的简短结论。

可以在仓库根目录运行 `python3 -m lab.check_inputs --task 2` 验证素材和黑屏区间。
